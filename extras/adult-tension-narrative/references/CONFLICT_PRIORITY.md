# Conflict Priority

## ATN-PRECEDENCE-001 — Priority order

When rules conflict:

1. system / platform safety requirements
2. stricter active project or world adult-eligibility rules
3. current Native RP safety / boundary / grant authority
4. player sovereignty and current explicit user instruction
5. successfully staged beat and branch-local runtime truth
6. Fixed Canon and immutable character identity
7. NPC knowledge provenance and control ownership
8. accepted continuity
9. physical-spatial possibility
10. character / context / POV plausibility
11. interactive pacing
12. sensory grounding
13. directness
14. prose rhythm
15. anti-slop polish

A lower layer never overrides a higher layer.

## ATN-PRECEDENCE-002 — Responsibility routing, not blanket override

Do not resolve cross-Skill conflicts by saying that one entire Skill wins.

Route the conflict to the owner defined in `references/OWNER_MATRIX.md`.

Examples:

- eligibility / grants / boundaries -> existing Adult Tension / Native RP Runtime;
- `sexuality_profile` / `sexuality_development` -> existing Adult Tension;
- `active_voice_mode` / POV / knowledge provenance -> existing Adult Tension / Native RP Runtime;
- beat granularity / physical-spatial planning -> Narrative Skill;
- sensory focal selection / prose rhythm / anti-slop -> Narrative Skill;
- aftermath facts -> existing Runtime;
- aftermath presentation timing -> Narrative Skill;
- directness -> composed ownership from `ATN-OWNER-003`;
- current explicit user request may narrow presentation scope without widening runtime authority.

If ownership is unclear, preserve existing Adult Tension behavior rather than assuming Narrative override.

## ATN-PRECEDENCE-003 — Examples

If a direct style would make a character behave out of character, preserve character identity.

If literary rhythm would skip a necessary physical transition, preserve physical continuity.

If extra detail would consume the player's next meaningful choice, preserve pacing.

If historical continuity conflicts with current authority, current authority wins.

If the Render Pass accidentally implies a new consequence, keep the successfully staged beat and revise the prose.

If the current user explicitly narrows detail or requests a fade/summary, follow the current user style request without widening authority.

## ATN-PRECEDENCE-004 — Persistent-development firewall

Scene-local psychophysical continuity never outranks the existing persistent `sexuality_development` evidence rules.

A vivid or intense scene is not, by itself, proof of a durable character-profile change.
